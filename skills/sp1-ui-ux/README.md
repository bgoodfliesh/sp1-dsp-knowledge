# sp1-ui-ux

Relational Control Grammar: a skill for designing coherent SP-1 instrument
interfaces. See `SKILL.md` for the constitution and pointers into
`references/`.

This skill is deliberately kept above implementation — it teaches how to
*derive* a control vocabulary for a new instrument, not the vocabulary of
any one existing instrument. Existing instruments' controls are examples of
the grammar, not the grammar itself, and shouldn't be copied wholesale into
a new design.

Extracted from a design discussion on 2026-09-22. Update the relevant
reference file (or `SKILL.md` for constitution-level changes) whenever a
new instrument design surfaces a new principle, exception, or sharper
example — see "Keeping this skill in sync" in `SKILL.md`.
