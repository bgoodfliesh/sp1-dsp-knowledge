# Community references

Catalog community articles, patches, ports, and independent implementations
with stable links, author/project attribution, dates, licenses, and confidence.
Unverified advice must remain clearly marked as research.

The lightweight-processing references supplied for SP-1 are summarized in
`lightweight-processing.md`. Each source has a separate YAML record and
directory so provenance can be upgraded independently as licensing and target
measurements become clearer.
