# Sources and provenance

This directory catalogs upstream research and implementation references. It is
not a default location for copied source. Each source record should include
the canonical URL, pinned revision or release, license, relevant modules,
hardware-independent assumptions, reuse/adaptation boundaries, and known
ports or independent implementations.

Use `registry.yaml` as the machine-readable index. Add a project-specific
record under its matching directory before relying on it in an implementation.

Research papers that inform DSP math, stability, or real-time architecture are
cataloged in `research-papers.md` and `research-papers.yaml`. Papers are
knowledge sources, not implementation or licensing approvals.
