# SP-1 Hardware

## Main SoC

**VERIFIED**

```
Nordic Semiconductor nRF52840
- ARM Cortex-M4F @ 64 MHz
- 256 KB RAM
- 1 MB flash
- Integrated 2.4 GHz Bluetooth radio (not antenna-connected in SP-1)
- Zephyr 4.3.1 firmware environment
```

## Flash and RAM Layout

**VERIFIED**

```
Boot sector:    0x00000 – 0x1FFFF (128 KB, bootloader)
Application:    0x20000 – 0xFFFFF (832 KB available)
RAM:            0x20000000 – 0x2003FFFF (256 KB)
```

Application firmware begins at `0x20000`. Bootloader owns lower region.

## Oscillator

**VERIFIED**

```
External 3.072 MHz oscillator
Control: P0.13
```

This oscillator drives the CS42L42 codec. The codec becomes the I2S master clock authority.

## Audio Codec: Cirrus Logic CS42L42

**VERIFIED**

```
Device:         CS42L42
I2C address:    0x48
I2C bus:        
    SCL = P1.11
    SDA = P1.07
Reset:          P0.15 (active-low)
```

The CS42L42 acts as **I2S master** and clock authority.

Register initialization must match established SP-1 firmware sequences. Do not invent codec configuration.

## Speaker Amplifier: TI TAS2505

**VERIFIED**

```
Device:         TAS2505
I2C address:    0x18
Reset:          P0.09 (active-low)
```

Requires SP-1-specific configuration. Do not assume generic TAS25xx initialization.

## I2S Audio Interface

**VERIFIED**

```
DOUT (data out):    P1.09
LRCLK (frame sync): P0.11
SCLK (bit clock):   P0.12
```

**Audio topology**:
- CS42L42: I2S master (generates LRCLK and SCLK from 3.072 MHz oscillator)
- nRF52840: I2S slave (audio source/sink)
- TAS2505: I2S slave (receives audio from nRF52840)

Audio sample rate: **48 kHz**

The 48 kHz frame timing generated by the codec is authoritative. Do not redesign clock architecture without hardware evidence.

## eMMC Storage: Toshiba THGBMNG5

**VERIFIED**

```
Device:     Toshiba THGBMNG5 4 GB eMMC
Interface:  1-bit SPI-style (not standard eMMC)
Frequency:  up to 32 MHz
CRC:        hardware
Controller: SPIM3
```

Pins:
```
CLK  = P0.06  (clock)
CMD  = P0.08  (command)
DAT0 = P0.07  (data)
RST  = P1.08  (reset)
VCCQ = P0.14  (power control)
```

**Critical constraint**: eMMC must be owned by a dedicated **streamer thread**. 

Do not allow:
- Arbitrary modules to independently access eMMC
- Audio thread to read/write eMMC
- Synchronous blocking operations during audio processing

## Control Inputs: SAADC

**VERIFIED**

Four faders and two resistive ladder controls (track selector, rocker/volume).

Ladder power must be enabled before reading:
```
LADDER_POWER = P1.10 (drive high)
```

SAADC channel assignments:
```
AIN0 = Track ladder selector
AIN1 = Rocker / volume ladder
AIN2 = Fader 3
AIN3 = Fader 1
AIN4 = Battery voltage
AIN6 = Fader 2
AIN7 = Fader 4
```

### Track Ladder

**VERIFIED** (12-bit ADC values)

```
Track 1 = 240  (±3% window: 233–247)
Track 2 = 450  (±3% window: 437–463)
Track 3 = 816  (±3% window: 792–840)
Track 4 = 1357 (±3% window: 1317–1397)
Play    = 2037 (±3% window: 1976–2098)
```

Simultaneous positions on the same ladder produce intermediate voltages. Do not treat as independent switches.

### Rocker / Volume Ladder

**INFERRED** (approximate 12-bit targets)

```
Rocker down  ≈ 450
Volume down  ≈ 816
```

Exact behavior depends on mechanical position and resistor network.

## Function Button

**VERIFIED**

```
P0.27 (push button)
```

Treat separately from ADC ladder inputs. Do not infer debounce timing without evidence.

## LEDs

**VERIFIED**

Eight LEDs in two banks:

Playback LEDs (four):
```
P1.13
P0.00
P1.12
P0.01
```

Track LEDs (four):
```
P0.29
P0.26
P1.15
P1.14
```

**Architecture rule**: LED state should be managed as firmware state (which LEDs should be on?), not as scattered GPIO commands throughout feature modules.

## Power Management

### Charger: BQ24232

**VERIFIED**

```
Device:     TI BQ24232
Signals:
    nCE    = P0.21  (charger enable, active-low)
    nCHG   = P0.22  (charging status, active-low)
    nPGOOD = P0.24  (power good, active-low)
    ISET   = P1.00  (charging current setting)
```

### Battery Monitoring

**VERIFIED**

```
Battery ADC input: P0.28 / AIN4
```

**Do not** infer battery percentage from voltage alone without explicit approximation documentation.

### System Power States

**VERIFIED**

```
SYSTEM_OFF mode available
Must clear RESETREAS before entering SYSTEM_OFF for correct reset-reason interpretation
```

Shutdown must leave audio, storage, Bluetooth, and peripherals in known safe states. **Do not** assume `SYSTEM_OFF` alone constitutes complete shutdown.

## Bluetooth Module: Infineon CYBT-353027-02

**VERIFIED**

```
Device:     Infineon CYBT-353027-02 (CYW20706A2 SoC)
- Independent Cortex-M3 CPU
- Bluetooth 4.2 radio + antenna
- 512 KB SPI flash
Communication: UART with nRF52840
```

### Bluetooth UART Configuration

**VERIFIED**

```
Baud rate:  115200
Data bits:  8
Stop bits:  1
Parity:     none
Logic level: 1.8 V
Protocol:   HCI over H4
```

### Bluetooth Module Safety

**CRITICAL**:

Never use `CHIP_ERASE` during normal firmware development.

Always preserve the Static Section before flashing new firmware:
1. Read Static Section before flashing
2. Verify it matches factory template
3. Restore it after flashing

Static Section contains:
- BD_ADDR (Bluetooth address)
- Keys
- RF calibration data

A disposable evaluation board is strongly recommended for developing/testing new AIROC firmware.

### Bluetooth Recovery

**VERIFIED** (known recovery sequence)

If Bluetooth module becomes unresponsive:

1. Hold CTS low
2. Pulse `RST_N` low for approximately 10 ms
3. Wait approximately 10 ms
4. Release CTS
5. Repeatedly issue HCI reset until acknowledgement received

**Never** put Bluetooth recovery into the audio execution path.

### Stock Bluetooth Firmware

**VERIFIED**

```
Classic Bluetooth A2DP sink (audio streaming)
```

**INFERRED**: BLE-MIDI not supported by stock firmware; requires custom AIROC/WICED application.
